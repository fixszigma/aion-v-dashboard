# GAC Aion V 602 — OBD2 BLE Live Telemetry Dashboard & PWA

แอปพลิเคชันแดชบอร์ดแสดงผลข้อมูลสด (Real-time Telemetry Dashboard) ผ่านพอร์ต OBD2 ด้วยการเชื่อมต่อ Bluetooth Low Energy (BLE 4.0+) สำหรับรถยนต์ไฟฟ้า **GAC Aion V 602** (รุ่นแบตเตอรี่ CATL LFP 75.3 kWh)

สร้างขึ้นโดยอ้างอิงโปรโตคอล UDS CAN Bus และสูตรการแปลงค่าดิบจากเอกสาร [AGENTS.md](./AGENTS.md) และโมดูล [aion_v_602_obd_decoder.py](./aion_v_602_obd_decoder.py)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

1. **ภาพรวมการขับขี่ (Overview Dashboard)**
   - มาตรวัดความเร็วทรงโค้ง (Gauge) 0–180 km/h แสดงผลแม่นยำ
   - มาตรวัดกำลังไฟฟ้าแบบสองทิศทาง (Bi-directional Power Gauge) แสดงทั้งการจ่ายไฟขับเคลื่อน (Drain kW) และการชาร์จไฟกลับขณะชะลอรถ (Regen kW)
   - วงแหวนสถานะแบตเตอรี่ (% SoC), ระยะทางวิ่งคงเหลือ (Range km) คำนวณแบบไดนามิกจากอัตราสิ้นเปลืองจริง
   - ระบบคำนวณและบันทึกทริป (Trip Integration): ระยะทางทริป (km), พลังงานที่ใช้ (kWh), พลังงาน Regen สะสม, อัตราสิ้นเปลืองเฉลี่ย (kWh/100 km) และระยะสะสม (Odometer)

2. **ระบบแบตเตอรี่แรงดันสูง (High-Voltage Battery Pack & Cells)**
   - แสดงกราฟแท่งเปรียบเทียบแรงดันรายเซลล์ครบทั้ง **112 เซลล์** (CATL LFP) พร้อมไฮไลต์เซลล์ต่ำสุด (Min) และสูงสุด (Max) แบบเรียลไทม์
   - คำนวณค่าผลต่างแรงดันสูงสุด-ต่ำสุด (Cell Delta mV) พร้อมระบบแจ้งเตือนสีส้มเมื่อเกิน 15 mV
   - แผนที่ความร้อน (Heat Grid) แสดงอุณหภูมิเซนเซอร์แบตเตอรี่ **24 จุด** และอุณหภูมิแผงวงจรควบคุม **BMU 16 จุด**
   - พลังงานชาร์จสะสม (CEC kWh), พลังงานจ่ายออกสะสม (CED kWh), ค่า SoH (%), แรงดันสายชาร์จ CC2 และไฟเลี้ยงโมดูล 12V

3. **ระบบขับเคลื่อน มอเตอร์ และความปลอดภัย (Drive & Dynamics)**
   - ความเร็วล้อแยกอิสระ 4 ล้อ (Front Left, Front Right, Rear Left, Rear Right)
   - รอบมอเตอร์ (RPM) ทิศทางหมุน และแรงบิดประมาณการ (Torque raw)
   - แรงดันไฟฟ้ากระแสตรง DC-Bus ของอินเวอร์เตอร์
   - วงกลมวัดแรง G (Friction Circle G-force Plot) แนวข้าง (Lateral) และแนวเร่ง/เบรก (Longitudinal)
   - มาตรวัดมุมเลี้ยวพวงมาลัย (Steering Angle °), Yaw Rate และแรงดันน้ำมันเบรกจากกล่อง Bosch IPB
   - ระบบแปลงไฟ DC-DC 12V และอุณหภูมิชุดชาร์จ CCU

4. **ระบบตัวถัง ลมยาง และแสงสว่าง (Body, TPMS & Lights)**
   - กราฟิกโมเดลรถจำลองแบบ SVG แสดงสถานะประตูเปิด/ปิด 4 บาน และฝาท้าย (รองรับพวงมาลัยขวา RHD)
   - ตรวจจับสถานะล็อกประตูรถ (Locked / Unlocked)
   - ระดับเปอร์เซ็นต์การเปิดกระจกหน้าต่างทั้ง 4 บาน
   - ไฟเลี้ยวซ้าย/ขวา, ไฟเบรก, ไฟถอยหลัง, และสวิตช์แป้นเบรก/เกียร์ P
   - แรงดันลมยางและอุณหภูมิลมยาง 4 ล้อ (TPMS psi / °C) พร้อมระบบไฮไลต์เตือนเมื่อลมยางอ่อนหรือผิดปกติ

5. **โหมดสาธิตเสมือนจริง (Interactive Driving Simulator / Demo Mode)**
   - สามารถเปิดทดสอบและดูฟังก์ชันทั้งหมดได้ทันทีโดยไม่ต้องต่อรถจริง
   - **แผงควบคุมการขับขี่ (Driving Control Console)**:
     - สลับโหมด: **อัตโนมัติ (Auto-Cycle)** หรือ **ควบคุมเอง (Manual Drive)**
     - **เกียร์ (Gear)**: เลือกเข้าเกียร์ `P`, `R`, `N`, `D` ส่งรหัสเกียร์ไปยังกล่อง VCU (`7E3 2103`) และสวิตช์ P ไปยัง IBCM (`720 1200`)
     - **คันเร่ง (Accelerator)**: ปุ่มเหยียบคันเร่งกดค้าง (Hold-to-accelerate) และสไลเดอร์ตั้งระดับคันเร่ง ส่งผลต่อรอบมอเตอร์ MCU (`7E4 1110`), แรงบิด (`7E4 1408`), กระแสแบตเตอรี่ BMS (`7E2 1404`), และความเร็วล้อทั้ง 4 ล้อใน VCU
     - **แป้นเบรก (Brake)**: ปุ่มเหยียบเบรกกดค้างและสไลเดอร์เบรก ส่งแรงดันน้ำมันเบรกไปยัง Bosch IPB (`710 1101`), ส่งสัญญาณสวิตช์แป้นเบรก (`720 1200`), จุดไฟเบรกท้ายรถ (`720 2101`), และจำลองระบบเบรกชะลอชาร์จไฟกลับ (Regen)
     - **พวงมาลัย (Steering)**: สไลเดอร์หมุนพวงมาลัย (-450° ถึง +450°) จำลองมุมเลี้ยว, คำนวณความเร็วล้อ 4 ล้อแยกอิสระตามหลัก Ackermann Steering Geometry (ล้อวงในหมุนช้ากว่าล้อวงนอก), แรงเหวี่ยงหนีศูนย์ Lateral G และ Yaw Rate
     - **ไฟเลี้ยว (Turn Signals)**: สลับไฟเลี้ยวซ้าย, ปิด, ไฟเลี้ยวขวา, หรือไฟฉุกเฉิน (Hazard) ส่งสถานะ Bitmask ไปยัง IBCM (`720 2100`) พร้อมไฟกระพริบบนกราฟิกรถจริง
     - **ประตู & แอร์ A/C**: จำลองการเปิด/ปิดประตูทั้ง 4 บานและฝาท้าย, สวิตช์ล็อกรถ, และระบบปรับอากาศ
     - **คีย์ลัดบนแป้นพิมพ์**: รองรับการขับขี่ผ่านคีย์บอร์ด (`W`/`↑` คันเร่ง, `S`/`↓`/`Space` เบรก, `1`/`2`/`3`/`4` เกียร์ P/R/N/D, `A`/`D` พวงมาลัย, `Q`/`E` ไฟเลี้ยว, `H` ไฟฉุกเฉิน)

6. **ระบบบันทึกและส่งออกข้อมูล (Data Logging & CSV Export)**
   - ปุ่มบันทึกข้อมูลสด (REC) ลงตารางทุกรอบความถี่สูง
   - ส่งออกข้อมูลเป็นไฟล์ CSV เพื่อนำไปวิเคราะห์ใน Excel / Python
   - ส่งออกภาพรวมสแนปช็อตข้อมูลล่าสุดเป็น JSON
   - หน้าต่างคอนโซล ELM327 แสดงคำสั่ง TX/RX พร้อม timestamp แบบเรียลไทม์

7. **ความปลอดภัยระดับสูงสุด (Read-Only Safety Policy)**
   - รันภายใต้นโยบาย **Read-Only** อย่างเคร่งครัด
   - อนุญาตเฉพาะคำสั่งอ่านค่า UDS Service `0x22` (Read Data By Identifier), `0x19` (Read DTCs) และ `0x3E` (Tester Present) เท่านั้น
   - คำสั่งเขียนค่า (`0x2E`), การสั่งงานรูทีน (`0x31`) หรือการควบคุมอุปกรณ์ (`0x2F`) ถูกบล็อกที่ระดับ Driver ไม่ให้ส่งออกพอร์ตอย่างเด็ดขาด

## 🛠️ ความต้องการของระบบและอุปกรณ์ที่รองรับ (Hardware & Requirements)

### ดองเกิล OBD2 ที่แนะนำ (BLE 4.0+)
- **OBDLink CX** (แนะนำสูงสุด เสถียรและประหยัดพลังงาน)
- **Vgate vLinker MC+ / BM+ / FS** (BLE mode)
- **Vgate iCar Pro BLE4.0**
- ดองเกิลมาตรฐาน ELM327 / STN ที่รองรับโปรโตคอล CAN Bus 500k 11-bit และใช้การเชื่อมต่อ Bluetooth Low Energy (BLE)
*(หมายเหตุ: ไม่รองรับ Bluetooth Classic SPP แบบดั้งเดิมใน Web Bluetooth)*

### เบราว์เซอร์ที่รองรับ
- **Google Chrome** หรือ **Microsoft Edge** บน Android หรือ Windows / macOS / ChromeOS
*(หมายเหตุ: iOS Safari ยังไม่เปิดรองรับ Web Bluetooth API จากโรงงาน)*

## 🚀 วิธีการเริ่มต้นใช้งาน (Quick Start)

### วิธีที่ 1: รันผ่าน Local Server (แนะนำ)
เนื่องจาก Web Bluetooth API กำหนดให้ทำงานภายใต้ `https://` หรือ `http://localhost` เพื่อความปลอดภัย:

1. ดับเบิลคลิกไฟล์ `start.bat` (บน Windows)  
   หรือพิมพ์คำสั่งผ่าน Terminal:
   ```bash
   python serve.py
   ```
2. เบราว์เซอร์จะเปิดไปที่ `http://localhost:8080/` โดยอัตโนมัติ
3. **ทดสอบโหมดจำลอง**: คลิกปุ่ม **"โหมดสาธิต"** เพื่อเริ่มจำลองข้อมูลการขับขี่ทันที
4. **เชื่อมต่อรถจริง**: เสียบดองเกิล OBD2 เข้าที่พอร์ตใต้พวงมาลัย สตาร์ทรถในสถานะ ON/READY แล้วคลิกปุ่ม **"เชื่อมต่อ BLE"** และเลือกอุปกรณ์ดองเกิลของคุณ

### วิธีที่ 2: รันการทดสอบ Unit Tests
ตรวจสอบความถูกต้องของฟังก์ชันถอดรหัส DID ทุกชุดและโครงสร้าง HTML/DOM:
```bash
cd dashboard
npm test
```

## ⚙️ การตั้งค่าขั้นสูง (Advanced Settings)

ในแท็บ **"ตั้งค่า"** ของแอป คุณสามารถปรับแต่งพารามิเตอร์การทำงานได้ตามต้องการ:
- **รอบความถี่สูง (Fast Interval)**: ปรับความเร็วรอบการดึงข้อมูลขับขี่ (ค่าเริ่มต้น 600 ms)
- **รอบความถี่ต่ำ (Slow Interval)**: ปรับความถี่รอบการดึงข้อมูลสถานะแพ็ก/เซลล์ (ค่าเริ่มต้น 20 วินาที)
- **โหมดดองเกิลโคลน (`ATCAF0`)**: สำหรับดองเกิลราคาประหยัดที่ตอบ `NO DATA` เมื่อใช้โหมดจัดเฟรมอัตโนมัติ ระบบจะใส่ความยาว PCI ไปในคำสั่งให้เอง
- **เลือกกลุ่มข้อมูล (Poll Filter)**: สามารถเลือกปิดกลุ่มข้อมูลที่ไม่ต้องการอ่านเพื่อเพิ่มความเร็วในการอัปเดตข้อมูลส่วนอื่น
- **รีเซ็ตทริป / รีเซ็ตเลขไมล์คำนวณ**: เพื่อเริ่มวัดระยะทางและประสิทธิภาพการใช้ไฟใหม่
